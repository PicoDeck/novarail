# Asset prompts

Where Nova Rail's generated assets came from, so they can be regenerated or
extended in the same style. Each prompt is quoted from the ComfyUI workflow
embedded in the file itself (`ffprobe -v error -show_entries
format_tags=prompt <file>`): it is the prompt that made that file.
